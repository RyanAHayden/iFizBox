Source Filters hide old, paid or unknown-iOS packages
One page layout for every source
Built-in VPN set up once, tested by itself
Custom installs are kept in My IPAs

- Sources > Manage has a new Filters page that hides old, unknown-iOS, paid or older-copy packages for all sources or one source; in the sideload app it lists only tweaks that can go into an app.
- Every source page, app sources and tweak repos alike, has the same layout: a header card, up to five of its apps, its description and news, and one Information group at the bottom.
- The built-in VPN asks to be added only once, while you set up This iPhone, and tests the connection by itself before it says Paired; on cellular, Cellular Shortcuts hands you ready-made Shortcuts to add.
- An app you install with Custom Install, from a link or from a URL is saved in My IPAs with your options, without a second download, so re-signing it uses that copy.
- Swipe a whole row off to delete apps, sources, IPAs and Wish List packages in the iOS 7, 13 and 26 styles, and tapping an IPA in the Files app opens its page ready to install.
- Smaller fixes: depictions no longer open as a blank sheet (Open in Safari where a site refuses), Details fills Preview from web depictions, sideload Search finds tweaks from your Tweak Sources, red menu buttons darken when held, and .dylib and .deb files can be picked again.
