Install Switch: one Shortcut for installs on cellular
Your own VPN comes back after installs
An IPA's page looks like an app's Details page
Add Tweaks opens as a page you can swipe back from

- This iPhone's setup now adds one Shortcut, Install Switch, which turns cellular data off and on around installs and reconnects your own VPN (like Tailscale) afterwards.
- In the sideload app, an IPA's page in Install IPAs now looks like an app's Details page, and its Add Tweaks opens as a normal page you can swipe back from, where tapping a tweak opens it.
- Tweaks in an app's Install popup now opens the Add Tweaks page too, and the popup asks again once you come back.
