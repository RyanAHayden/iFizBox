Share opens each style's own menu
Install Switch opens only when it's needed
Installs on cellular with the Install Switch
Fewer system-only tweaks in App Tweaks

- Share in the iOS 7, iOS 13 and iOS 26 styles now opens that style's own menu, with each app's icon, instead of the iOS 6 share sheet.
- On Wi-Fi with no other VPN on, installs on This iPhone no longer flip to Shortcuts and back; the Install Switch now opens only on cellular or to bring back a VPN like Tailscale.
- Installs on This iPhone now work on cellular with the Install Switch. If you added the Install Switch before, add it again from Settings > Installation & Signing > This iPhone, since its Shortcut has changed.
- When the built-in VPN doesn't start, the install now says so and offers Check Again or the Signing Server, instead of sending you to LocalDevVPN.
- In the app without a jailbreak, tweaks that only change iOS itself, like Aerial, no longer show in App Tweaks, Search or section counts once they have been checked.
