Cydia-style Details page for packages and apps, and Source links that land on Sources
Packages and apps open a Details page like Cydia's: icon rows, Preview, More Information, Filesystem Content
Website add-source links open the Sources tab with the new source loading there
Home Screen icon follows Theme > Mode; Tailscale names the machine after the phone model

- Details page for packages and apps in every era, with Change Package Settings and a centred footer.
- Adding a source from a website's link lands on the Sources tab's list, with the new source loading there.
- The Home Screen icon follows Theme > Mode: Light or Dark gives both icon slots that tone.
- Tailscale: the machine is named after the phone model, and Sign Out keeps the machine key, so the next Sign In comes back as the same machine.
- The Running page has one black bar with Apps | Log in its title, redrawn from Cydia's.
- A single-app upgrade on This iPhone ends with Open <app>, as an install does.
- The IPA page footer follows Install Apps With.
- Back buttons follow a page title set after the page opened; links from pages on Home slide in.
