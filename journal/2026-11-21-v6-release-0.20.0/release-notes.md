This iPhone installs: Tailscale checked first, one pairing at a time, Use the Signing Server when it fails

- Theme > Style iOS 26: large titles, card sheets, the floating glass tab bar with Search as its own circle, and capsule bar buttons. In the app on iOS 26+, switches, search fields, alerts, action sheets, long-press menus and the scope bar are iOS's own.
- Add Tweaks opens as its own page under an app's Details, with search, ADD / ADDED rows and the tweaks made for that app.
- Manage > Sources picks sources with circles and a Select All / Delete toolbar, like Installed's Manage.
- When an install through This iPhone can't reach the phone, its alert and log offer Use the Signing Server.
- This iPhone checks Tailscale before the pairing, runs one pairing at a time, and says that installs through Tailscale work only on Wi-Fi. The Pairing page names Tailscale when that is the way in.
- Lite signs every app up front and installs up to 3 at once through This iPhone.
- Installation & Signing shows icons on every row, and Install Apps With shows the chosen route and whether it is paired.
- Console Logs keep sideload signs, installs and queue runs from the first line; Report an Issue opens a prefilled GitHub issue.
- Theme > Light / Dark preview: drag the top bar to move the split, and try the sample.
- iOS 6 style: black status-bar strip over the nav bar, and a launch screen to match. The Running page draws the iOS 7 and iOS 13 styles too.
- Home Screen icons on iOS 26+: Clear and Tinted draw the globe as glass.
- The icon badge drops to what is still waiting as soon as a queue run ends.
- Fixes: Installed opens a source app's own entry; website add-source links land on Sources; a Reinstall while iOS installs the same app for another app says so; swipes from a My IPAs button show Delete; Add to App hides when the tweak can't go into an app.
